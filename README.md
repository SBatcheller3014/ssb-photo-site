This is a simple, mixed theme website specific to a freelance photographer; myself. Given my limited coding experience, AI models were consulted in creating and troubleshooting the code. The layout was my own design, other than the gallery grid styling. 

VSCodium (with Git for Windows integration) installed a local PC is the primary coding tool. All code gets 'pushed' to a public, Git Hub Repository for storage. The website's underlying custom domain is registered with Cloudflare, and hosted via [Cloudflare] Pages; also integrated to Git Hub. A custom Wufoo contact form is integrated via css + js. 

Albeit a simple structured website, robots.txt and sitemap.xml is added, primarily to support 'best practices'.
